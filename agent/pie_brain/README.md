# pie_brain — Pie mate 학습 자료

「Pie mate 학습 가이드라인」대로 만든 파일이에요. 1:1 Pie와 그룹방 Pie mate가 같은 자료를 씁니다.

| 파일 | 담는 것 | 한도 |
|---|---|---|
| `persona.md` | 공통 성격 — 정체성·말투·반드시·금지·되묻기·답 형식 (순서 고정) | 1,200자 |
| `modes.md` | `## chat` · `## group` 채널 차이만 | 섹션당 300자 |
| `examples.jsonl` | 모범 대화 82개 (태그 11종, both 71%) | ideal 250자 |
| `knowledge/*.md` | 앱 사실 46조각 (`##` 하나 = 조각 하나, `키워드:` 줄 필수) | 조각당 400자 |
| `calc_examples.jsonl` | ⑥ 계산 해석 예시 (이미 코드가 읽음) | — |
| `../../tests/pie_eval.jsonl` | 평가 88문제 (까다로운 문제 24%) | 80개 이상 |

## 고친 뒤 꼭 돌리기

```
py tests/pie_brain_check.py
```
필드·태그·글자 수·개수·예시↔평가 문장 중복·개인정보·화면에 없는 버튼 이름을 검사해요 (서버·Kiln 불필요, 토큰 0).
오류가 0이어야 올려요.

## 채점기가 지켜야 할 규칙 (다음 단계에서 만들 때)

- `room` 한 줄에서 `멤버 A·B·C`, `총액 N원`, `결제자 X`를 읽어 앱과 같은 조건(참여자·총액·결제자)으로 호출해요.
- `mode: both` 문제를 **그룹 모드로 돌릴 때는 앞에 "파이야 "를 붙여요.** 그룹방은 이름을 안 부른 사용법 질문을 코드가 무시하기 때문이에요.
- `expect`: `card` = 계산 결과가 나옴(1:1 말풍선·그룹 확인 카드) · `ask` = 되묻기 · `refuse` = 거절 · `silent` = 그룹에서 답 안 함(코드 판단).
- `must` 전부 포함 · `must_any` 하나 이상 · `must_not` 하나라도 있으면 실패 · `max_chars` 기본 1:1 400자, 그룹 200자.
- `expect_situation`·`expect_domain`은 ④ 상황 인식 백엔드를 붙인 뒤부터 채점해요.

## 코드 연결 (적용됨)

`agent/brain.py`가 이 폴더를 읽어 1:1 Pie·그룹 Pie mate 프롬프트를 조립한다 (파일을 고치면 다음 호출부터 반영).
태그는 코드가 규칙으로 정하고(토큰 0), 지식은 사실 질문(사용법·진행 상황·대기·이의제기)은 키워드 1점, 그 밖은 2점 이상일 때만 넣는다.
형식 검사: `python tests/pie_brain_check.py` · 로더 검사: `python tests/brain_check.py`
